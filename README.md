# 🚗 【ROS 2 / OpenCV】車載カメラとオドメトリを統合した衝突前90度自律回避制御

## 1. プロジェクト概要
* **概要:** ROS 2 Humble および Gazebo シミュレータ上の TurtleBot3 (Waffle Pi) において、車載カメラ画像（OpenCV）とオドメトリ（`/odom`）を統合し、障害物と完全に接触する前の安全な距離で認識して、車体の傾き・視線ブレを起こさずに滑らかに+90度（左）へ旋回して前進再開する自律回避システムの実装。
* **目的:** Physical AI領域における「物理的・システム的制約（リアルタイム性、車体の慣性モーメント・ロール運動によるカメラ視野の破綻、検知遅延）」を考慮した、安全で堅牢な自律移動制御アルゴリズムの検証。

---

## 2. 使用技術・開発環境
* **OS / シミュレータ:** Ubuntu 22.04 LTS (Docker環境), Gazebo (TurtleBot3 World)
* **ミドルウェア:** ROS 2 Humble (Python 3.10 / rclpy)
* **主要ライブラリ:** OpenCV (cv_bridge, Cannyエッジ検出, HSVカラーフィルタリング), NumPy, Math
* **評価車両:** TurtleBot3 Waffle Pi

## 3. Physical AIとしての工夫と試行錯誤のプロセス（★最重要アピール点）

### ① 課題1: 急激な旋回運動に伴う「車体の傾き（ロール運動）」とカメラ視野の破綻
* **現象:** 前進状態（`linear.x = 0.15`）から障害物検知直後に一気に旋回（`angular.z = 0.65`）へ切り替えた際、左右のタイヤにかかるトルク差と慣性モーメントにより車体が横揺れを起こし、車体上部に固定されたカメラ映像が大きく斜めに傾いて視野が歪む問題が発生した。
* **仮説・調整:** 直進から旋回へ即座に遷移させるのではなく、障害物検知直後に「姿勢安定化状態（`BRAKE`）」のステートを挟み、0.2秒間速度を完全ゼロにして車体の揺れを収めてから、旋回角速度を `0.45 rad/s` に制限して滑らかに回転させるステートマシン制御を導入した。
* **結果:** 車体の横揺れとカメラ視野の傾きを完全抑制し、物理的にも安全で視認性の高いスムーズな旋回運動を実現した。

### ② 課題2: 障害物との接触・衝突直前での回避動作発動
* **現象:** 初期コードではカメラ画像の下端（車体直前）付近を監視していたため、障害物に極限まで接近・衝突する直前になってから旋回動作に入っていた。
* **仮説・調整:** 画像の監視領域（ROI）を車体直前ではなく「前方警戒エリア（画高の30%〜70%）」へ引き上げ、Cannyエッジ検出における非ゼロピクセル数の閾値を1200に設定して遠方の段階で察知するロジックに変更した。
* **結果:** 衝突を起こす十分手前の安全距離で障害物を予兆検知し、余裕を持って回避行動へ移行できるようになった。

### ③ 課題3: カメラ認知の視認性向上と正確な90度角度制御
* **現象:** Gazebo上の無地の灰色球体は背景と同化しやすく認知的破綻を起こしやすかった点、および単一の画像処理のみでは旋回角度が浅く（約30度）完全に回避しきれないケースが存在した。
* **仮説・調整:** 
  1. 球体の生成SDFにおいてマテリアルを `Gazebo/Red`（赤色）へ変更し、OpenCVのHSV二重色相抽出（`bitwise_or`）によって100%捕捉可能な視認性を確保。
  2. ROS 2のオドメトリトピック（`/odom`）をサブスクライブしてクォータニオンから現在のYaw角を算出。「目標角度 = 現在角 + 90度（$\pi/2$ rad）」を設定し、残り角度（`Remaining`）を判定しながら正確に90度向きを変えてから前進を再開する状態管理を実装した。

## 4. セットアップと実行手順

### 1. ワークスペースのクローンとビルド
```bash
cd ~/ros_ws/src
git clone [https://github.com/KY-yota/turtlebot3-autonomous-avoidance.git](https://github.com/KY-yota/turtlebot3-autonomous-avoidance.git)
cd ~/ros_ws
colcon build
source install/setup.bash
# ターミナル1: Gazeboの起動
export TURTLEBOT3_MODEL=waffle_pi
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py

# ターミナル2: 90度自律回避ノードの起動
cd ~/ros_ws && source install/setup.bash
ros2 run physicalai_pubsub yolo_tracker
---

### Step 2. スクリプトコードを追加する

`README.md` の保存が終わったら、リポジトリにPythonのソースコードを追加します[cite: 7]。

1. リポジトリのトップ画面に戻り、検索窓の右側にある **`＋` ボタン（Add file） ➔ `Create new file`** をクリックします[cite: 7]。
2. **ファイル名（Name your file...）** の欄に以下のように入力します[cite: 7]：
   `physicalai_pubsub/yolo_tracker.py`
   *(スラッシュ `/` を打ち込むと自動的にフォルダ階層になります)*[cite: 7]
3. コード入力欄に、前回修正・作成した **`SmoothAvoidance90Deg` の Python コード**（姿勢安定化ブレーキ＋90度旋回コード）を貼り付けます[cite: 7]。
4. 右上の **`Commit changes...`** ボタンを押して保存します[cite: 7]。

同様の手順で `physicalai_pubsub/moving_ball.py` も追加しておくと完璧です[cite: 7]！
